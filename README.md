# Management Panel

## Описание проекта

Management Panel — это Django-приложение, реализующее веб-панель контроля управленческих действий контейнера безопасности. Программное средство предназначено для предотвращения потери управления собственной инфраструктурой при переносе её в облачную среду.

Приложение позволяет моделировать обработку управленческих запросов, проверять полномочия пользователей, контролировать критичные действия, выполнять журналирование, отслеживать доступность системы и формировать показатели качества программного средства.

## Основные функции

- обработка управленческих запросов;
- проверка ролей пользователей;
- контроль второго подтверждения для критичных действий;
- проверка политики безопасности;
- фиксация решений `allow`, `deny`, `rollback`;
- журналирование управленческих действий;
- отображение текущего состояния системы;
- построение таблиц и графиков;
- расчет метрик качества программного средства;
- публикация метрик в формате Prometheus через endpoint `/metrics/`.

## Метрики качества

В проект добавлен блок метрик качества программного средства. Метрики рассчитываются на основе состояния системы, журнала управленческих действий и результатов обработки запросов.

Реализованные метрики:

- `management_panel_requests_total` — общее количество обработанных управленческих запросов;
- `management_panel_allow_total` — количество разрешенных действий;
- `management_panel_deny_total` — количество отклоненных действий;
- `management_panel_rollback_total` — количество откатов;
- `management_panel_availability_status` — текущий статус доступности системы;
- `management_panel_audit_log_records_total` — количество записей журнала;
- `management_panel_https_enabled_status` — состояние включения HTTPS;
- `management_panel_certificate_valid_status` — состояние действительности сертификата;
- `management_panel_insecure_http_detected_status` — признак небезопасного HTTP-доступа;
- `management_panel_quality_score` — интегральная оценка качества программного средства.
